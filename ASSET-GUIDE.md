# Yuke® Portfolio — Asset Preparation Guide

Everything below was read from the current `index.html`. **You do not need to edit any code.** Upload each file with the **exact name** shown, into the **exact folder**, and it appears on its page automatically. A slot with no file keeps showing its grey placeholder, so you can add assets gradually.

## 1. Rules (read once)

| Rule | Detail |
|---|---|
| Folders | `images/social-media/`, `images/paid-media/`, `images/creative/`, `images/brand-stories/` (create them in GitHub: **Add file → Create new file**, type `images/social-media/readme.txt`, commit; repeat for each). |
| Names | Lowercase, hyphens, no spaces. Case matters on GitHub Pages. |
| Image format | JPG for photos and designs (quality about 85). PNG or WebP also work with the same name (`.png` / `.webp`). |
| Image size | Long edge **1600 px**, under **400 KB** each. Screenshots: capture at full size, then export at 1600 px. |
| Double-page spreads | **2400 × 1600 px** (3:2), JPG under 700 KB. |
| Video | **MP4, H.264**, under **25 MB** (GitHub's browser upload limit). 1080p max, about 30–60 seconds. Short vertical clips 1080 × 1920. |
| Video cover (optional) | Same name plus `-poster.jpg`, e.g. `tiktok-2-poster.jpg`. Without it the browser shows the first frame, so start on a good frame. |
| Cropping | Nothing is ever cropped. Any ratio works. The ratio column below is the shape the slot is designed for. |
| Privacy | Blur client names, budgets, emails and anything confidential. Only show results you can verify. |

## 2. How the pages use your images

Each chapter is four pages (six if it has a spread):

1. **Opener (left page)**: slot 1. The picture sits in a landscape-ish area (about 440 × 300 px on a desktop), so **landscape or square images look best**. Tall images appear small.
2. **Overview (right page)**: text only.
3. **Gallery (left page)**: slots 2 and 3. Chapters 1, 3, 5 of each volume show them **side by side** (portrait-friendly, each about 210 px wide). Chapters 2, 4, 6 show them **stacked** (landscape-friendly).
4. **Strategy page (right page)**: text only.
5. **Spread (optional, 2 pages)**: one image across both pages.

Not image slots: the four covers (made in code), the carousel, About and Contact.

## 3. Totals and a sensible order

65 slots in total (60 chapter slots + 5 spreads). You do not need all of them. **Minimum strong set (about 24 files):** slots 1 to 3 for X, Instagram, TikTok, Meta Ads, Graphic Design, Brand Storytelling, plus each volume's spread.

## 4. Known limits (and how to work around them)

- **Growth and analytics screenshots** have no dedicated slot. Put them in slot 1 (account screenshot), or merge profile + analytics into one image. If you want a separate analytics slot per platform, ask and it can be added.
- **TikTok** shows a vertical video next to a wide campaign visual, so the wide image is small. Use a vertical or square image for `tiktok-3`.
- **Numbers and text** (followers, impressions, responsibilities, strategy, achievements) are typed in the `MAGS` list at the top of the script in `index.html`, not uploaded. They show `—` until you fill them, and the homepage figures (340K+ etc.) still need their source and period confirmed.
- Changed a file but the old one shows? Hard refresh (Ctrl+F5) after GitHub Pages rebuilds (1–2 minutes).

## 5. How to upload

1. Open your repo on github.com, go into the right `images/...` folder.
2. **Add file → Upload files**, drag the correctly named files in, **Commit changes**.
3. Wait 1–2 minutes, refresh the site, open the volume and flip to the chapter.
